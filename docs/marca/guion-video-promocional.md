# Guion del video promocional de evidentIA

Propuesta de video para difundir el proyecto. Está pensado para LinkedIn, YouTube y la presentación del proyecto, con una versión corta para Instagram y TikTok.

- **Público**: abogados, estudios jurídicos y aseguradoras que reciben fotos como prueba de siniestros.
- **Mensaje central**: hoy una foto se edita o se genera con IA en segundos; evidentIA ayuda a revisarla antes de confiar en ella, con un informe claro y sin reemplazar al perito.
- **Duración**: versión completa de 75 segundos; versión corta de 25 segundos.
- **Formato**: 16:9 para la versión completa y 9:16 (vertical) para la corta.
- **Tono**: serio y confiable, con ritmo. Nada de alarmismo ni de promesas absolutas.

## Reglas que el video tiene que respetar

Salen de la especificación del proyecto y valen también para el marketing:

1. **No prometer veredictos (RN27).** No decir "detecta fraudes", "descubre la verdad" ni "sabe si una foto es falsa". Sí decir "encuentra indicios", "te muestra señales", "te ayuda a decidir".
2. **Recomendar siempre al profesional.** El cierre menciona que el informe es una evaluación preliminar y que se recomienda consultar a un perito.
3. **No usar imágenes de casos reales.** Los ejemplos se arman con fotos propias, de bancos de imágenes libres o generadas a propósito con IA.
4. **No mostrar un puntaje global** que combine las cuatro capas: cada capa muestra su propio nivel de indicio.
5. **Solo imágenes.** El sistema no analiza video, audio ni documentos; el video no tiene que sugerir lo contrario.

## Estilo visual y sonido

- **Colores**: los de la paleta de marca (verde claro, verde oliva, blanco y negro). Fondos negros para los momentos de marca y blancos para la interfaz.
- **Logos**: usar las piezas de [`piezas/`](piezas/). Para animar la apertura del ojo conviene el isotipo transparente (`20-isotipo-transparente.png`) y, para el cierre, el logo con letras blancas (`22-logo-y-nombre-blanco-transparente.png`).
- **Tipografía**: una sans serif geométrica en negrita, parecida a la del nombre, para los títulos (por ejemplo, Montserrat o Poppins), y la misma en peso liviano para los textos secundarios.
- **Movimiento**: el marco de cuatro esquinas funciona como "visor" que encuadra cada cosa que se analiza. Es el recurso que une todo el video.
- **Música**: electrónica suave y tensa al principio (escenas 1 a 3), que se abre y se vuelve más luminosa cuando aparece la marca. Usar música libre de derechos.
- **Subtítulos**: siempre activados; gran parte del público mira sin sonido.

## Qué hace falta para producirlo

| Recurso | De dónde sale |
|---|---|
| Foto de ejemplo de un choque (original y versión editada) | Foto propia o de un banco libre; la versión editada se arma a propósito |
| Imagen de un choque generada con IA | Generada con cualquier herramienta de imágenes |
| Grabaciones de pantalla del sistema | Frontend de evidentIA en el entorno de desarrollo, con datos de prueba |
| Un informe PDF de ejemplo | Generado por el sistema con las imágenes de ejemplo |
| Voz en off | Grabación propia o voz sintética, en español rioplatense |
| Edición | CapCut, Canva o DaVinci Resolve |
