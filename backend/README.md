# Backend

API REST del sistema, escrita en Python con Flask 3.1. Organizada en capas según la [constitución](../docs/constitucion.md): `rutas → servicios → repositorios → modelos`, con componentes transversales para seguridad, análisis, integraciones y tareas en segundo plano.

El mapa de carpetas está en [docs/arquitectura/estructura-del-repositorio.md](../docs/arquitectura/estructura-del-repositorio.md).

> Las instrucciones de instalación y ejecución se completan en la funcionalidad 001.
